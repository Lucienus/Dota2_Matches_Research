# Research scripts supporting the paper

These scripts document the implementations used for the paper's model search,
data and graph audits, repeated sampling, computational-cost measurements, and
figures. They connect the reported experiments to their original source code.

Execution requires the historical workspace layout, imports, and input artifacts
referenced by each script. For the independently verified reconstruction,
prediction, scoring, and table-export workflow, follow the root `README.md` and
its public entry points.
